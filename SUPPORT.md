# Getting help

- **Questions** about using the packages: open an issue with the [question form](https://github.com/milten89/OpenUrzednik.NET/issues/new?template=0-question.yml). Polish or English is fine.
- **Missing or unexpected data:** check [NBP's API](https://api.nbp.pl/en.html) first. The library returns what NBP publishes; the [OpenUrzednik.Nbp README](src/OpenUrzednik.Nbp/README.md#data-availability-and-limits) lists when NBP publishes and what the API limits are.
- **Bugs and feature requests:** use the other [issue forms](https://github.com/milten89/OpenUrzednik.NET/issues/new/choose).
- **Security vulnerabilities:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Code of conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

The maintainer works on this project in spare time and offers no paid support. The [Versioning and support](README.md#versioning-and-support) section says which versions get fixes.
