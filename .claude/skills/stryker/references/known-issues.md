# Known Stryker.NET issues for this repository

Issues of [stryker-mutator/stryker-net](https://github.com/stryker-mutator/stryker-net/issues) that can affect this setup: C#, `netstandard2.0;net8.0;net10.0` libraries mutated on `net10.0`, strong-named assemblies, central package management, Nerdbank.GitVersioning, xUnit v3 on Microsoft.Testing.Platform (`test-runner: mtp`), Stryker.NET **5.1.0** (released 2026-11-10, the latest release on 2026-11-20), Windows locally and Ubuntu in CI.

Reviewed 2026-11-07: all 176 open issues and the 149 closed since 2024-11-01, plus keyword searches. Re-checked 2026-11-20 for 5.1.0: every tracked issue and its PRs (merge commits compared with the tag) and the issues updated since 2026-11-07; no 5.1.0 regression affects this setup. Issues about F#, VB, Blazor/Razor, WPF/MAUI, Unity, .NET Framework test projects, the dashboard, baselines and `since` were left out.

"Fixed after 5.1.0" means the fix was merged after the 5.1.0 tag (2026-11-10) and is in no release yet; "fixed in 5.1.0" rows stay for reading older reports. Verification marks: **source** = checked in the source, cited from 5.1.0 (`dotnet-stryker@5.1.0`, commit `7052fa6`; the 5.0.0 citations were re-mapped on 2026-11-20, paths under `src/`); **here** = seen in this repository's reports or runs; **repro** = reproduced in a minimal project (2026-11-07 research); **unverified** = taken from the issue.

When a shard behaves oddly, check this list first, then search upstream: `gh issue list -R stryker-mutator/stryker-net --search "<symptom>"`.
