# Known Stryker.NET issues for this repository

Issues of [stryker-mutator/stryker-net](https://github.com/stryker-mutator/stryker-net/issues) that can affect this setup: C#, `netstandard2.0;net8.0;net10.0` libraries mutated on `net10.0`, strong-named assemblies, central package management, Nerdbank.GitVersioning, xUnit v3 on Microsoft.Testing.Platform (`test-runner: mtp`), Stryker.NET **5.0.0** (released 2026-09-11, the latest release on 2026-11-07), Windows locally and Ubuntu in CI.

Reviewed 2026-11-07: all 176 open issues and the 149 closed since 2024-11-01, plus keyword searches. Issues about F#, VB, Blazor/Razor, WPF/MAUI, Unity, .NET Framework test projects, the dashboard, baselines and `since` were left out.

"Fixed after 5.0.0" means the fix was merged after 2026-09-11 and is in no release yet. Verification marks: **source** = checked in the 5.0.0 source (`dotnet-stryker@5.0.0`, commit `6e77a34`, paths under `src/`); **here** = seen in this repository's reports or runs; **repro** = reproduced in a minimal project (2026-11-07 research); **unverified** = taken from the issue.

When a shard behaves oddly, check this list first, then search upstream: `gh issue list -R stryker-mutator/stryker-net --search "<symptom>"`.
