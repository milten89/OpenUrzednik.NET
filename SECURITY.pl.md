# Polityka bezpieczeństwa

🇬🇧 Pełna polityka bezpieczeństwa jest po angielsku: [SECURITY.md](SECURITY.md). Tu opisujemy tylko, jak zgłosić podatność. Jeśli wersje się różnią, obowiązuje angielska.

Jeśli znajdziesz podatność bezpieczeństwa w OpenUrzednik.NET (np. sposób na wyciek klucza API, podatność SSRF przez spreparowany URL albo problem z walidacją danych z odpowiedzi urzędów), **nie zgłaszaj jej w publicznym issue**.

- **Najlepiej:** użyj zakładki **Security → Report a vulnerability** w tym repozytorium (GitHub Private Vulnerability Reporting).
- **Jeśli nie możesz skorzystać z GitHuba:** napisz na **security@ochodek.net**.

Opisz:

- pakiet (np. Core, Nbp) i jego wersję,
- kroki do odtworzenia,
- potencjalny wpływ.

Nie ujawniaj szczegółów, dopóki nie opublikujemy komunikatu o podatności (GitHub Security Advisory). Terminy odpowiedzi, obsługiwane wersje i sposób ujawniania podatności opisuje [angielska polityka](SECURITY.md).
